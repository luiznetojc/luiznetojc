## 🚀 Projeto em destaque

### [delamain](https://github.com/luiznetojc/delamain)
Harness portátil para desenvolvimento assistido por IA. Um catálogo central de skills e workflows de agentes, instalável e versionado por repositório, que funciona em **Claude Code**, **Codex CLI**, **Google Antigravity** e **Orca**.

- Workflows declarativos em DAG (feature, bugfix, refactor, security review, test improvement) com gates obrigatórios
- Handoffs entre runtimes com snapshot de estado do Git e hash de arquivos para detectar drift
- Telemetria local em SQLite de tokens e custo, com comparação A/B entre workflows e modelos
- Perfis prontos para .NET, Node.js e TypeScript

`Node.js` `TypeScript` `SQLite` `JSON Schema`
